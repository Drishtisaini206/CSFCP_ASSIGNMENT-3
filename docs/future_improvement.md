Future Improvements and Enhancements
To expand the functionality and professional capability of the Console Calculator, the following improvements are planned:
User History: Implement a simple logging feature to store and display the last 5 calculations performed in the current session.
Scientific Mode: Add more complex mathematical operations, such as square root (sqrt), power (pow), and modulus (%).
Refactoring for Clarity: Separate the input handling and calculation logic into distinct files or modules for improved code structure and maintainability.
Unit Testing: Implement automated unit tests for all core functions (add, subtract, multiply, divide) to ensure reliability.
